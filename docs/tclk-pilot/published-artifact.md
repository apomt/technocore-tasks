# Published pilot artifact

The sanitized pilot is intended for the existing public repository
[`apomt/technocore-tasks`](https://github.com/apomt/technocore-tasks). The immutable pilot commit
and resolved URLs are recorded here by a follow-up metadata commit after the artifact commit is
created; a Git commit cannot contain its own hash.

Publication does not post a tclk frame, create a deal, select a counterparty, or authorize a
signature. The public artifact contains synthetic tooling and public references only.
